# Asset credits

Every photograph in `assets/guides/` comes from Wikimedia Commons and is
reproduced here under its own licence. Each is resized to 720 px wide and
re-encoded as JPEG; nothing else is altered.

**On ShareAlike.** Several of these are CC BY-SA. Including a work in an
application is distributing a *collection*, which does not place the
application under the work's licence. Resizing is an adaptation, so the
resized images in `assets/guides/` are themselves offered under the same
licence as their source — that obligation attaches to those files, never to
the code in this repository.

The app shows this list in Settings → Photo credits. Attribution is a licence
condition, not a courtesy: if an image is added here it must appear there too,
and `test/asset_credits_test.dart` fails the build if the two disagree.

## Methods without a photograph

`coldBrew`, `kopiSaring` and `kopiTalua` ship without one. Commons has no
usable image of any of them: cold brew returns branded takeaway cups and video
stills, kopi saring returns South Indian filter coffee, and `kopi talua`
returns no files at all under any licence — only `teh talua`, which is the
tea. A guide is shown without a photograph rather than with the wrong one.
